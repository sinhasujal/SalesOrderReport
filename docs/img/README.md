# Screenshots

Evidence that the project actually runs, rather than only passing a syntax check.

Save the two images here with **exactly these filenames** — the main README links to
them by name:

| Filename | What it should show |
|---|---|
| `adt-console-output.png` | The ADT console after running `ZCL_SO_REPORT_CLOUD` with F9 — the three order rows plus `Rows : 3`, `Orders : 2`, `Total value : 123000.00 INR` |
| `abap-unit-green.png` | The ABAP Unit result view after `Ctrl+Shift+F10` on `ZCL_SO_REPORT_CLOUD` — four tests, green |

## Taking them

- Crop to the relevant panel. A full-screen 4K shot of Eclipse is unreadable in a README.
- Leave the class name and the ADT toolbar visible — that is what shows it is real ADT
  against a real system, not a mock-up.
- PNG, not JPG. Text stays sharp.
- Keep each one under about 500 KB.

## Optional third

`adt-project.png` — the Project Explorer showing `ZSALES_ORDER` with the two tables, the
CDS view and the classes activated. Good supporting evidence that the DDIC objects exist,
which is the part the job description cares about most.

## Why this matters

There is no shareable live link for an SAP project — the system is behind authentication
and the trial is temporary. Screenshots of the SAP tooling are the accepted proof in this
domain, and they are what moves "executed on a real SAP system" from PENDING to done.
